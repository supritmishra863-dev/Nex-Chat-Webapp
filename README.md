# 💬 NexChat

NexChat is a modern real-time chat web application designed to provide a simple, fast, and interactive messaging experience.

🌐 **Live Demo:** https://nex-chat-webapp.vercel.app/

## ✨ Features

- 🔐 User Signup & Login
- 💬 Real-time Messaging
- 🟢 Online/Offline Status
- ✍️ Typing Indicator
- 📞 Voice Calling
- 📹 Video Calling
- 🔒 Lock Chat
- 🕵️ Secret Mode
- 🚫 Block Users
- ↩️ Reply to Messages
- ↪️ Forward Messages
- 🗑️ Delete for Me
- 🗑️ Delete for Everyone
- 😀 Emoji Support
- 📎 Image & File Sharing

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js
- Socket.IO
- REST APIs

### Database
- MongoDB
- MongoDB Atlas

### Deployment
- Vercel — Frontend
- Render — Backend
